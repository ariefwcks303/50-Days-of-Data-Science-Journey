# 🚀 50-Days-of-Data-Science-Journey

Selamat datang di jurnal pembelajaran teknis saya! Repositori ini mendokumentasikan perjalanan saya selama 50 hari dalam mendalami dunia **Data Science dan Machine Learning**. 

Tujuan utama dari perjalanan ini adalah untuk membangun intuisi data, mengasah *coding skill* (Python), dan menciptakan portofolio yang komprehensif dari proyek-proyek praktis.

## 📈 Roadmap Perjalanan
Perjalanan ini dibagi menjadi beberapa fase pengembangan kompetensi:

| Modul | Notebook | Skill utama yang dikuasai |
|-------|----------|---------------------------|
| **1. Fondasi Analisis Data** | 01–10 | pandas, eksplorasi data, cleaning, missing values, EDA, pipeline EDA reusable |
| **2. Visualisasi & Storytelling** | 11–18 | matplotlib, seaborn, plotly interaktif, time series, dashboard KPI, data storytelling |
| **3. ML: Regresi** | 19–28 | regresi linear/Ridge/Lasso, KNN, Decision Tree, Random Forest, Gradient Boosting, RMSE/R², cross-validation, Pipeline |
| **4. ML: Klasifikasi** | 29–40 | Logistic Regression, KNN, Decision Tree, Random Forest, SVM, Naive Bayes, data tidak seimbang, ROC/AUC, confusion matrix, GridSearchCV |
| **5. Unsupervised Learning** | 41–45 | K-Means, elbow & silhouette, hierarchical clustering, PCA, deteksi anomali (Isolation Forest) |
| **6. Capstone End-to-End** | 46–50 | churn, predictive maintenance, sistem rekomendasi, prediksi penjualan, & **portfolio** |

## 🛠 Tech Stack
* **Languages:** Python, SQL
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Tools:** Google Colab, GitHub, VS Code
* **Cloud & DevOps:** AWS, Azure (Integrated in later stages)
